Шаблоны страниц

Шаблон приглашения. Сервер заполняет данные в элементы по id:

  • #guest-name — имя гостя
  • #events — карточки событий (дата, место, +1) с выбором «придёте ли»
  • #companion-section — блок имени спутника (если разрешён +1)
  • #questions — форма вопросов
  • #submit-btn и #message — кнопка отправки и сообщение об ошибке (JS добавляется автоматически)

Шаблон подтверждения — страница, которую видит гость после отправки ответа:

  • #guest-name — имя гостя
  • #message — текст «Ваш ответ сохранён» (или «вы ещё не ответили»)
  • #summary — сводка ответов (события, спутник, вопросы); если блока нет — сводка не показывается
  • #back-link — ссылка «изменить ответ» / «открыть приглашение»

Хотите простое «спасибо» без деталей? Уберите из шаблона блок #summary.

Изображения для шаблонов

Загрузите фото (например, фото пары) и вставьте его URL в шаблон через кнопку «Вставить». Ссылки вида /uploads/1 работают в обоих шаблонах.
